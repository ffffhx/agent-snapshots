# 真实历史 RAG 评测：2026-09-11

已完成冻结语料、三路检索、两轮真实 DeepSeek 生成和逐条 Agent 评分。结果显示：找到目标会话不代表证据完整或回答正确。当前可作为开发基线，不能代表生产准确率，也没有证明 DeepSeek 优于本地模型。

- 原文 gold 引用和答案要点由 Agent 标注、核对，尚未独立人工复核。历史助手的陈述不等于独立验证的现实事实。
- 数据 SHA-256：`8fe1100d33713bed8d84141143bddfe6ab4f774f45495228955b739561f6558d`。
- 向量模型：本地 `qwen3-embedding:0.6b`；生成：`deepseek:deepseek-flash`，温度 0、关闭 thinking、最多 2400 输出 token、JSON 输出。
- 检索一次冻结证据，两轮生成复用；第二轮反转执行顺序。保留数据、提示词、代码、证据和答案哈希，逐次记录调用结果。

## 生成结果

共 60 次生成调用，无接口错误。46 次可回答题运行中，44 次返回答案、2 次错误拒答；这 44 次不等于 44 次答对。14 次无答案题运行全部由模型拒答，检索门槛拒答为 0。两次错误拒答来自同一道题。

生成阶段 P50 为 1.217 秒、P95 为 1.780 秒，不包含检索时间。总输入 97,598 token、输出 7,169 token。根据缓存命中及峰谷价格估算约 0.0113–0.0225 美元，不是账单实付，也不包含本地向量计算成本。价格依据 [DeepSeek 官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)。

逐条核对的代表性问题：

- `profile-existing`：正确会话中有明确答案，但证据打包截断关键句，两轮都错误拒答。
- `clip-verify`：回答引用了早期验证，漏掉用户所问后续功能的状态同步与重启验证；引用有依据仍可能答非所问或不完整。
- `profile-template`：主要方案正确，但把后续已修复的早期诊断当作当前结论，存在时间混淆。
- `games-assets`、`games-commit`：部分结论与所引用证据不完全对应，或把计划中的细节带入最终结果。

未依据这些测试结果调整生产检索、提示词或模型。未来若据此调优，应保留本轮作为回归记录，并新增未见测试集。

人工复核可从待审模板开始，评分器要求答案哈希一致、理由完整、每个主张均被评估；待审项不会计为通过。评分维度参考 [Ragas 指标体系](https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/)，实现为本项目 rubric，并未运行 Ragas 或声称获得标准认证。

本轮是小规模便利抽样；项目仅 4 个，题目存在组内相关性。两轮重复不增加独立样本量。尚缺独立人工双标与一致性分析、大规模干扰语料、自然查询分布及更多对抗/长上下文案例。当前测试集已被检查，后续不能再把它当作完全未见数据。
