运行方式

选择临时审阅或常驻运行

临时审阅适合手动开一段时间；macOS LaunchAgent 适合登录后自动保持本地查看器可用。

临时审阅

不用克隆，直接运行

手动启动本地只读查看器；关闭终端或停止进程后服务结束。

npx codex-snapshots@latest serve --port 4321

# 或者全局安装
npm install -g codex-snapshots
codex-snapshot serve --port 4321

macOS LaunchAgent

安装成后台常驻

从源码目录安装为用户级后台服务；登录 macOS 后自动保持查看器可用。

pnpm install
pnpm snapshot:install-daemon
pnpm snapshot:daemon:status
